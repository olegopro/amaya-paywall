# Amaya Paywall — заметки для работы в репозитории

Тестовое задание: мобильный paywall детской игры. Nuxt 4 (структура `app/`), TypeScript strict,
UI-библиотек нет — свои стили на SCSS и токенах. Подробности запуска и решений — в README.md.

## Правила проекта

- **Компоненты экрана презентационные.** Данные — в `props`, действия — в `emit`; запросы и
  состояние живут в `app/composables/usePaywall.ts`, страница их связывает. Так экран целиком
  показывается в Storybook без Nuxt.
- **В компонентах импорты явные** (`vue`, `~/utils/...`, `#shared/types/paywall`) — на автоимпорты
  Nuxt компоненты не опираются, иначе витрина не соберётся. В `app/pages` и `app/composables`
  автоимпорты Nuxt обычны, в server-коде — автоимпорты Nitro (`defineEventHandler`, `getCookie`).
- **Цены и список тарифов — в `shared/offers.ts`**: один источник для server routes, витрины и фикстур.
  Клиент присылает только `offerId`.
- **Тексты интерфейса русские**, комментарии в коде — тоже, по делу и без пересказа кода.
- **Токены оформления** — в `app/assets/css/main.css`; цвета состояний подобраны с контрастом ≥ 4.5:1.
- **Стили компонентов — SCSS** (`<style scoped lang="scss">`): короткие классы внутри корневого класса
  компонента, состояния модификатором (`&.is-selected`, `&:disabled`), вложенность не глубже трёх уровней.
  Имён с `__` и `--` нет, БЭМ в проекте не используется.
- Минимум по заданию: новые зависимости, абстракции и украшения только если без них требование не выполнить.

## Проверки перед коммитом

```bash
npm run typecheck && npm run lint && npm run build
```
